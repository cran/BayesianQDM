Single binary endpoint

This vignette describes the analysis of a proof-of-concept (PoC) study with one binary endpoint (Kang, Yamaguchi and Han, 2026). vignette("overview") introduces the decision criteria.

Model

In group \(k\) (\(k = t\) for treatment, \(c\) for control), \(y_k\) of \(n_k\) subjects respond, \(y_k \sim \textrm{Binomial}(n_k, \pi_k)\), and the response rate has the prior distribution \(\pi_k \sim \textrm{Beta}(a_k, b_k)\) (prior_beta(); prior_beta(0.5, 0.5) is the Jeffreys prior). The posterior distribution is \[\pi_k \mid y_k \sim \textrm{Beta}(a_k + y_k, b_k + n_k - y_k),\] and the treatment effect is \(\theta = \pi_t - \pi_c\). The posterior probability \(\Pr(\theta > q \mid D)\) is computed by numerical integration (pbetadiff()).

For the predictive criterion, \(m_k\) future subjects of group \(k\) have \(\tilde y_k\) responders, whose posterior predictive distribution is beta-binomial. The future effect is \(\tilde\theta = \tilde y_t / m_t - \tilde y_c / m_c\), and its predictive probabilities are computed exactly by summation (pbetabinomdiff()).

Decision for observed data

A study with 12 subjects in each group, Jeffreys priors and a posterior criterion with \(\theta_{TV} = 0.2\), \(\theta_{MAV} = 0.1\), \(\gamma_{go} = 0.5\) and \(\gamma_{nogo} = 0.8\):

jeffreys <- prior_beta(0.5, 0.5)
crit <- criterion_posterior(theta_tv = 0.2, theta_mav = 0.1,
                            gamma_go = 0.5, gamma_nogo = 0.8)
des <- design_binary(n_t = 12, n_c = 12, prior_t = jeffreys,
                     prior_c = jeffreys, criterion = crit)
dec <- qdm_decide(des, data_t = data_binary(12, 9),
                  data_c = data_binary(12, 3))
dec
#> Decision: Go
#>   Go:   P(theta > 0.2 | data) = 0.9304 (threshold 0.5, met)
#>   NoGo: P(theta <= 0.1 | data) = 0.02338 (threshold 0.8, not met)
#> Posterior distributions
#>   Treatment: Beta(a = 9.5, b = 3.5)
#>   Control:   Beta(a = 3.5, b = 9.5)

The probabilities of the Go and NoGo regions are the posterior probabilities \(\Pr(\theta > 0.2 \mid D)\) and \(\Pr(\theta \le 0.1 \mid D)\), which pbetadiff() gives from the posterior parameters:

post_t <- dec$posterior_t
post_c <- dec$posterior_c
pbetadiff(0.2, a_t = post_t[["a"]], b_t = post_t[["b"]],
          a_c = post_c[["a"]], b_c = post_c[["b"]], lower.tail = FALSE)
#> [1] 0.9303746
pbetadiff(0.1, a_t = post_t[["a"]], b_t = post_t[["b"]],
          a_c = post_c[["a"]], b_c = post_c[["b"]])
#> [1] 0.02338322

With 9 and 3 responders, the decision is Go.

Forms of the control group

External control data

External data enter through a power prior: with \(n_e\) subjects, \(y_e\) responders and weight \(a_0\) (from 0 to 1), the posterior distribution of the response rate is \[\textrm{Beta}(a + a_0 y_e + y, \; b + a_0 (n_e - y_e) + n - y).\] With \(a_0 = 0\) the external data are ignored, and with \(a_0 = 1\) they are pooled with the current data. Borrowing half of 20 external control subjects with 5 responders:

des_ext <- design_binary(
  n_t = 12, n_c = 12, prior_t = jeffreys, prior_c = jeffreys,
  criterion = crit,
  external_c = borrow(data_binary(n = 20, y = 5), a0 = 0.5)
)
dec_ext <- qdm_decide(des_ext, data_t = data_binary(12, 9),
                      data_c = data_binary(12, 3))
dec_ext$posterior_c
#>  a  b 
#>  6 17

The external data add 2.5 responders and 7.5 non-responders to the posterior distribution of the control group, and the probability of the Go region becomes 0.955 (without them, 0.93).

Without a concurrent control group (n_c = 0), the control group can be described by the external data alone:

des_ext0 <- design_binary(
  n_t = 12, n_c = 0, prior_t = jeffreys, prior_c = jeffreys,
  criterion = crit,
  external_c = borrow(data_binary(n = 40, y = 10), a0 = 1)
)
qdm_decide(des_ext0, data_t = data_binary(12, 9))
#> Decision: Go
#>   Go:   P(theta > 0.2 | data) = 0.9684 (threshold 0.5, met)
#>   NoGo: P(theta <= 0.1 | data) = 0.006469 (threshold 0.8, not met)
#> Posterior distributions
#>   Treatment: Beta(a = 9.5, b = 3.5)
#>   Control:   Beta(a = 10.5, b = 30.5)

External treatment data (external_t) can be used in the same way with any form of the control group.

Hypothetical control

For an uncontrolled study, Kang et al. (2026, Section 4.1.4) describe the control response rate by a hypothetical control, \(\pi_c \sim \textrm{Beta}(a_t + z, b_t + n_t - z)\), where \(z\) is the number of responders expected among \(n_t\) control subjects. This is obtained with prior_c equal to prior_t and hypothetical(data_binary(n_t, z)):

des_hyp <- design_binary(
  n_t = 12, n_c = 0, prior_t = jeffreys, prior_c = jeffreys,
  criterion = crit,
  hypothetical_c = hypothetical(data = data_binary(n = 12, y = 3))
)
qdm_decide(des_hyp, data_t = data_binary(12, 9))
#> Decision: Go
#>   Go:   P(theta > 0.2 | data) = 0.9304 (threshold 0.5, met)
#>   NoGo: P(theta <= 0.1 | data) = 0.02338 (threshold 0.8, not met)
#> Posterior distributions
#>   Treatment: Beta(a = 9.5, b = 3.5)
#>   Control:   Beta(a = 3.5, b = 9.5)

Fixed control

A single-arm study is often compared with a known benchmark, such as the response rate of the standard of care reported in the literature. With fixed_c, the control response rate is a known value \(\pi_{c0}\), the treatment effect is \(\theta = \pi_t - \pi_{c0}\), and prior_c is not used (it must be NULL). The probability of the Go region is then the Beta probability \(\Pr(\pi_t > \pi_{c0} + \theta_{TV} \mid D)\). A study with 20 subjects compared with a benchmark of 0.2:

crit_fix <- criterion_posterior(theta_tv = 0.2, theta_mav = 0.05,
                                gamma_go = 0.8, gamma_nogo = 0.8)
des_fix <- design_binary(n_t = 20, n_c = 0, prior_t = prior_beta(1, 1),
                         criterion = crit_fix, fixed_c = 0.2)
dec_fix <- qdm_decide(des_fix, data_t = data_binary(20, 11))
dec_fix
#> Decision: Go
#>   Go:   P(theta > 0.2 | data) = 0.9151 (threshold 0.8, met)
#>   NoGo: P(theta <= 0.05 | data) = 0.001687 (threshold 0.8, not met)
#> Posterior distributions
#>   Treatment: Beta(a = 12, b = 10)
#>   Control:   fixed value 0.2
pbeta(0.2 + 0.2, 1 + 11, 1 + 20 - 11, lower.tail = FALSE)
#> [1] 0.9150757

With fixed_c = 0, the effect is the response rate itself, and the thresholds are response rates. For the predictive criterion, the future effect is \(\tilde y_t / m_t - \pi_{c0}\), and m_c is not used.

Predictive criterion

The predictive criterion asks whether a future study with \(m_t\) and \(m_c\) subjects would observe an effect larger than \(\theta_{NULL}\). With 40 subjects per group in the future study and \(\theta_{NULL} = 0\):

des_pred <- design_binary(
  n_t = 12, n_c = 12, prior_t = jeffreys, prior_c = jeffreys,
  criterion = criterion_predictive(theta_null = 0, m_t = 40,
                                   gamma_go = 0.9, gamma_nogo = 0.7)
)
dec_pred <- qdm_decide(des_pred, data_t = data_binary(12, 9),
                       data_c = data_binary(12, 3))
dec_pred
#> Decision: Go
#>   Go:   P(future theta > 0 | data) = 0.9835 (threshold 0.9, met)
#>   NoGo: P(future theta <= 0 | data) = 0.01647 (threshold 0.7, not met)
#> Posterior distributions
#>   Treatment: Beta(a = 9.5, b = 3.5)
#>   Control:   Beta(a = 3.5, b = 9.5)
post_t <- dec_pred$posterior_t
post_c <- dec_pred$posterior_c
pbetabinomdiff(0, m_t = 40, a_t = post_t[["a"]], b_t = post_t[["b"]],
               m_c = 40, a_c = post_c[["a"]], b_c = post_c[["b"]],
               lower.tail = FALSE)
#> [1] 0.9835266

The Go and NoGo regions of the predictive criterion are complementary, so their probabilities add up to 1. A Gray decision is then possible only when \(\gamma_{go} + \gamma_{nogo} > 1\).

Smaller effects as favorable

For a safety endpoint, such as the occurrence of an adverse event, a smaller rate in the treatment group is favorable. With direction = "less" in the criterion, the Go region is \(\theta < \theta_{TV}\) and the NoGo region is \(\theta \ge \theta_{MAV}\), with \(\theta_{TV} < \theta_{MAV}\). Here the decision is Go if the rate of the adverse event is likely to be reduced by more than 0.1, and NoGo if it is likely not to be reduced:

crit_ae <- criterion_posterior(theta_tv = -0.1, theta_mav = 0,
                               gamma_go = 0.6, gamma_nogo = 0.7,
                               direction = "less")
des_ae <- design_binary(n_t = 12, n_c = 12, prior_t = jeffreys,
                        prior_c = jeffreys, criterion = crit_ae)
dec_ae <- qdm_decide(des_ae, data_t = data_binary(12, 2),
                     data_c = data_binary(12, 6))
dec_ae

Calibration of the thresholds

qdm_calibrate() chooses \(\gamma_{go}\) as the smallest value of a grid for which the probability of meeting the Go criterion under scenario_go is at most target_go, and \(\gamma_{nogo}\) in the same way for the NoGo criterion under scenario_nogo. Here the Go criterion should be met with probability at most 0.05 when the treatment has no effect, and the NoGo criterion with probability at most 0.2 when the effect is 0.3:

cal <- qdm_calibrate(des,
                     scenario_go = data.frame(pi_t = 0.2, pi_c = 0.2),
                     scenario_nogo = data.frame(pi_t = 0.5, pi_c = 0.2),
                     target_go = 0.05, target_nogo = 0.2)
cal
